{# Reader controls: colour scheme and text size. Included once from base.html, which is the only thing all 38 screens share — the site has seven nav archetypes and several screens (login, MFA, blocked, maintenance, the payment receipt) with no chrome at all to hang a button on. Bottom-left, because the sign-language module already occupies bottom-right on eight of these pages. It is a real form posting to /preferences, not a pair of script hooks. The people the text-size control exists for are the least likely to be on a current browser, so it has to work before watiq.js has loaded and still work if it never does; watiq.js upgrades it to apply the change without a reload. Selected state is carried by aria-pressed alone, styled in _theme.css, so the enhancement only has to flip an attribute rather than juggle utility classes. `theme`, `text_scale` and the *_class values come from the context processor in app.py, which reads the cookie this form sets. #}
